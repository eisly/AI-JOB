# 业务后端接口（页面调用）

## 获取求职画像

**接口地址**：`/api/v1/profile`

**请求方式**：`GET`

**请求数据类型**：`无请求体`

**响应数据类型**：`application/json`

**接口描述**：读取确认事实与偏好。初始facts未知字段null、skills为空。

**权限**：用户。

**请求示例**：

```http
GET /api/v1/profile HTTP/1.1

```

**请求参数**：

| 参数名称 | 参数说明 | 请求类型 | 是否必须 | 数据类型 | schema |
| --- | --- | --- | --- | --- | --- |
| Authorization | Bearer 用户accessToken | header | true | string |  |

**响应状态**：

| 状态码 | 说明 | schema |
| --- | --- | --- |
| 200 | 操作成功 | CommonResult&lt;ProfileVO&gt; |
| 400 / 401 / 403 / 404 / 409 / 429 / 500 | 详见公共错误码 | CommonError |

**响应参数**：

| 参数名称 | 参数说明 | 类型 | schema |
| --- | --- | --- | --- |
| code | 业务码，200成功/202受理 | integer |  |
| msg | 提示信息 | string |  |
| data | 业务数据 | ProfileVO | ProfileVO |
| traceId | 关联排障ID | string |  |
| &emsp;userId | 用户ID | uuid |  |
| &emsp;profileVersion | 画像版本/乐观锁 | integer |  |
| &emsp;targetRole | 预设岗位名称或自定义岗位名称，≤32字符 | string |  |
| &emsp;candidateType | INTERNSHIP/CAMPUS/EXPERIENCED | string |  |
| &emsp;cities | 行政区划编码，≤5 | string[] |  |
| &emsp;minMonthlySalaryCents | 税前月薪下限，人民币分 | integer? |  |
| &emsp;maxMonthlySalaryCents | 税前月薪上限 | integer? |  |
| &emsp;facts | 已确认事实 | ResumeFacts | ResumeFacts |
| &emsp;activeResumeVersionId | 生效简历版本 | uuid? |  |
| &emsp;updatedAt | UTC时间 | datetime |  |

**响应示例**：

```json
{
```

## 保存求职偏好

**接口地址**：`/api/v1/profile/preferences`

**请求方式**：`PUT`

**请求数据类型**：`application/json`

**响应数据类型**：`application/json`

**接口描述**：替换偏好，成功后画像版本递增。事实只能通过简历确认修改。

**权限**：用户。

**请求示例**：

```json
{
  "expectedProfileVersion": 3,
  "targetRole": "JAVA_BACKEND",
  "candidateType": "CAMPUS",
  "cities": [
    "330100"
  ],
  "minMonthlySalaryCents": 1200000,
  "maxMonthlySalaryCents": 1800000
}
```

**请求参数**：

| 参数名称 | 参数说明 | 请求类型 | 是否必须 | 数据类型 | schema |
| --- | --- | --- | --- | --- | --- |
| Authorization | Bearer 用户accessToken | header | true | string |  |

| targetRole | 岗位方向枚举 | body | true | string |  |
| candidateType | INTERNSHIP/CAMPUS/EXPERIENCED | body | true | string |  |

| minMonthlySalaryCents | 非负整数分，可null | body | false | integer? |  |

## 查询技能目录

**接口地址**：`/api/v1/skills`

**请求方式**：`GET`

**请求数据类型**：`无请求体`

**响应数据类型**：`application/json`

**接口描述**：只返回启用技能；q用于名称匹配。

**权限**：用户。

**请求示例**：

```http
GET /api/v1/skills HTTP/1.1

```

**请求参数**：

| 参数名称 | 参数说明 | 请求类型 | 是否必须 | 数据类型 | schema |
| --- | --- | --- | --- | --- | --- |
| Authorization | Bearer 用户accessToken | header | true | string |  |
| q | ≤50字符 | query | false | string |  |

**响应状态**：

| 状态码 | 说明 | schema |
| --- | --- | --- |
| 200 | 操作成功 | CommonResult&lt;SkillVO[]&gt; |
| 400 / 401 / 403 / 404 / 409 / 429 / 500 | 详见公共错误码 | CommonError |

**响应参数**：

| 参数名称 | 参数说明 | 类型 | schema |
| --- | --- | --- | --- |
| code | 业务码，200成功/202受理 | integer |  |
| msg | 提示信息 | string |  |
| data | 业务数据 | SkillVO[] | SkillVO[] |
| traceId | 关联排障ID | string |  |

**响应示例**：

```json
{
  "code": 200,
  "msg": "操作成功",
  "data": [
    {
      "code": "redis",
      "name": "Redis",
      "parentCode": "backend",
      "enabled": true
    }
  ],
  "traceId": "demo-trace-20261027"
}
```
