# 业务后端接口（页面调用）

## 新增投递记录

**接口地址**：`/api/v1/applications`

**请求方式**：`POST`

**请求数据类型**：`application/json`

**响应数据类型**：`application/json`

**接口描述**：手动创建投递记录，可关联有权查看的系统岗位，也可手动录入。

**权限**：用户。

**请求示例**：

```json
{
  "jobId": "30000000-0000-4000-8000-000000000001",
  "companyName": "云启智能（虚构）",
  "jobTitle": "Java 后端开发工程师",
  "cityCode": "330100",
  "education": "本科",
  "salaryText": "10–16K",
  "description": "参与企业级平台后端开发",
  "status": "APPLIED",
  "plannedDate": "2026-10-25",
  "appliedDate": "2026-10-26",
  "note": "等待反馈"
}
```

**请求参数**：

| 参数名称 | 参数说明 | 请求类型 | 是否必须 | 数据类型 | schema |
| --- | --- | --- | --- | --- | --- |
| Authorization | Bearer 用户 accessToken | header | true | string | |
| jobId | 有权查看的岗位 ID；手动录入可省略或为 null | body | false | uuid? | |
| companyName | 公司名称，去除首尾空白后 1..100 字符 | body | true | string | |
| jobTitle | 岗位名称，去除首尾空白后 1..100 字符 | body | true | string | |
| cityCode | 城市编码，最多 12 字符 | body | false | string? | |
| education | 学历展示文本，最多 50 字符 | body | false | string? | |
| salaryText | 薪资展示文本，最多 100 字符 | body | false | string? | |
| description | 岗位简述，最多 1000 字符 | body | false | string? | |
| status | 投递状态，省略时为 PLANNED | body | false | string | |
| plannedDate / appliedDate | 计划投递 / 实际投递日期 | body | false | date? | |
| interviewDate / closedDate | 面试 / 结束日期 | body | false | date? | |
| note | 备注，最多 2000 字符 | body | false | string? | |

**响应状态**：

| 状态码 | 说明 | schema |
| --- | --- | --- |
| 200 | 操作成功 | CommonResult&lt;ApplicationVO&gt; |
| 400 / 401 / 403 / 404 / 409 / 429 / 500 | 详见公共错误码 | CommonError |

**响应参数**：

| 参数名称 | 参数说明 | 类型 | schema |
| --- | --- | --- | --- |
| code | 业务码 | integer | |
| msg | 提示信息 | string | |
| data | 投递记录 | ApplicationVO | ApplicationVO |
| traceId | 关联排障 ID | string | |
| &emsp;id | 投递记录 ID | uuid | |
| &emsp;jobId | 关联岗位 ID，可为 null | uuid? | |
| &emsp;companyName / jobTitle | 公司名称 / 岗位名称快照 | string | |
| &emsp;cityCode / education / salaryText / description | 城市编码、学历、薪资和岗位简述 | string? | |
| &emsp;status | PLANNED / APPLIED / INTERVIEWING / CLOSED | string | |
| &emsp;plannedDate / appliedDate / interviewDate / closedDate | 四个阶段的日期，未填写为 null | date? | |
| &emsp;note | 备注 | string? | |
| &emsp;version | 乐观锁版本，初始为 1 | integer | |
| &emsp;createdAt / updatedAt | 创建 / 更新时间，UTC | datetime | |

**响应示例**：

```json
{
  "code": 200,
  "msg": "操作成功",
  "data": {
    "id": "a0000000-0000-4000-8000-000000000001",
    "jobId": "30000000-0000-4000-8000-000000000001",
    "companyName": "云启智能（虚构）",
    "jobTitle": "Java 后端开发工程师",
    "cityCode": "330100",
    "education": "本科",
    "salaryText": "10–16K",
    "description": "参与企业级平台后端开发",
    "status": "APPLIED",
    "plannedDate": "2026-10-25",
    "appliedDate": "2026-10-26",
    "interviewDate": null,
    "closedDate": null,
    "note": "等待反馈",
    "version": 1,
    "createdAt": "2026-10-26T02:00:00Z",
    "updatedAt": "2026-10-26T02:00:00Z"
  },
  "traceId": "demo-trace-20261027"
}
```

**业务规则**：名称和岗位信息由用户提交并保存为快照；岗位更新、关闭或取消收藏不改变已有记录。关联岗位无权查看或不存在返回 404。允许同一岗位创建多条记录。日期格式为 `YYYY-MM-DD`，未提供的可空字段返回 null。

## 查询投递记录

**接口地址**：`/api/v1/applications`

**请求方式**：`GET`

**请求数据类型**：`无请求体`

**响应数据类型**：`application/json`

**接口描述**：分页查询当前用户的投递记录，可按状态筛选。

**权限**：用户。

**请求示例**：`GET /api/v1/applications?status=APPLIED&current=1&size=20`

**请求参数**：

| 参数名称 | 参数说明 | 请求类型 | 是否必须 | 数据类型 | schema |
| --- | --- | --- | --- | --- | --- |
| Authorization | Bearer 用户 accessToken | header | true | string | |
| status | 单个状态；不传查全部 | query | false | string | |
| current | 页码，从 1 开始，默认 1 | query | false | integer | |
| size | 每页 1..100，默认 20 | query | false | integer | |

**响应状态**：

| 状态码 | 说明 | schema |
| --- | --- | --- |
| 200 | 操作成功 | CommonResult&lt;Page&lt;ApplicationVO&gt;&gt; |
| 400 / 401 / 403 / 429 / 500 | 详见公共错误码 | CommonError |

**响应参数**：`data.total` 为总数，`data.records` 为 ApplicationVO 数组，`data.current` 和 `data.size` 为当前分页信息。ApplicationVO 字段见新增接口。

**响应示例**：

```json
{
  "code": 200,
  "msg": "操作成功",
  "data": {"total": 0, "records": [], "current": 1, "size": 20},
  "traceId": "demo-trace-20261027"
}
```

**业务规则**：仅查询本人记录；按 `createdAt DESC, id DESC` 排序。非法状态和分页参数返回 400。

## 查询投递详情

**接口地址**：`/api/v1/applications/{id}`

**请求方式**：`GET`

**请求数据类型**：`无请求体`

**响应数据类型**：`application/json`

**接口描述**：查询一条投递记录。

**权限**：用户。

**请求示例**：`GET /api/v1/applications/a0000000-0000-4000-8000-000000000001`

**请求参数**：

| 参数名称 | 参数说明 | 请求类型 | 是否必须 | 数据类型 | schema |
| --- | --- | --- | --- | --- | --- |
| Authorization | Bearer 用户 accessToken | header | true | string | |
| id | 投递记录 ID | path | true | uuid | |

**响应状态**：200 返回 `CommonResult<ApplicationVO>`；400 / 401 / 403 / 404 / 429 / 500 返回 `CommonError`。

**响应参数及示例**：`data` 为完整 ApplicationVO，同新增投递记录的响应示例。

**业务规则**：仅本人可查看；不存在或属于其他用户均返回 404。

## 修改投递记录

**接口地址**：`/api/v1/applications/{id}`

**请求方式**：`PATCH`

**请求数据类型**：`application/json`

**响应数据类型**：`application/json`

**接口描述**：修改记录信息或投递状态。

**权限**：用户。

**请求示例**：

```json
{
  "expectedVersion": 1,
  "status": "INTERVIEWING",
  "interviewDate": "2026-10-28",
  "note": null
}
```

**请求参数**：

| 参数名称 | 参数说明 | 请求类型 | 是否必须 | 数据类型 | schema |
| --- | --- | --- | --- | --- | --- |
| Authorization | Bearer 用户 accessToken | header | true | string | |
| id | 投递记录 ID | path | true | uuid | |
| expectedVersion | 当前记录版本 | body | true | integer | |
| companyName / jobTitle | 公司 / 岗位名称，约束同新增接口 | body | false | string | |
| cityCode / education / salaryText / description | 展示信息，约束同新增接口 | body | false | string? | |
| status | 四种状态之一 | body | false | string | |
| plannedDate / appliedDate / interviewDate / closedDate | 对应阶段日期 | body | false | date? | |
| note | 备注，最多 2000 字符 | body | false | string? | |

**响应状态**：200 返回 `CommonResult<ApplicationVO>`；400 / 401 / 403 / 404 / 409 / 429 / 500 返回 `CommonError`。

**响应参数及示例**：`data` 为更新后的完整 ApplicationVO，结构同新增接口；上述示例成功后 `status` 为 `INTERVIEWING`，`interviewDate` 为 `2026-10-28`，`note` 为 null，`version` 为 2。

**业务规则**：至少提交一个修改字段；省略字段保持不变，可空字段传 null 表示清空。jobId 不可修改。状态可前进、回退或重新开启，不自动改变日期。版本不一致返回 409 `VERSION_CONFLICT`；不存在或属于其他用户返回 404。

## 删除投递记录

**接口地址**：`/api/v1/applications/{id}`

**请求方式**：`DELETE`

**请求数据类型**：`无请求体`

**响应数据类型**：`application/json`

**接口描述**：删除本人投递记录。

**权限**：用户。

**请求示例**：`DELETE /api/v1/applications/a0000000-0000-4000-8000-000000000001?expectedVersion=1`

**请求参数**：

| 参数名称 | 参数说明 | 请求类型 | 是否必须 | 数据类型 | schema |
| --- | --- | --- | --- | --- | --- |
| Authorization | Bearer 用户 accessToken | header | true | string | |
| id | 投递记录 ID | path | true | uuid | |
| expectedVersion | 当前记录版本，正整数 | query | true | integer | |

**响应状态**：200 返回 `CommonResult<boolean>`；400 / 401 / 403 / 404 / 409 / 429 / 500 返回 `CommonError`。

**响应示例**：

```json
{"code":200,"msg":"操作成功","data":true,"traceId":"demo-trace-20261027"}
```

**业务规则**：物理删除，不影响岗位或收藏；版本不一致返回 409，不存在或属于其他用户返回 404，重复删除返回 404。

## 查询投递看板统计

**接口地址**：`/api/v1/applications/summary`

**请求方式**：`GET`

**请求数据类型**：`无请求体`

**响应数据类型**：`application/json`

**接口描述**：统计当前用户各状态的投递记录数量。

**权限**：用户。

**请求示例**：`GET /api/v1/applications/summary`

**请求参数**：

| 参数名称 | 参数说明 | 请求类型 | 是否必须 | 数据类型 | schema |
| --- | --- | --- | --- | --- | --- |
| Authorization | Bearer 用户 accessToken | header | true | string | |

**响应状态**：200 返回 `CommonResult<ApplicationSummaryVO>`；401 / 403 / 429 / 500 返回 `CommonError`。

**响应参数**：`data.total` 为总记录数，`data.counts` 为各状态数量。

**响应示例**：

```json
{
  "code": 200,
  "msg": "操作成功",
  "data": {
    "total": 4,
    "counts": {"PLANNED": 1, "APPLIED": 1, "INTERVIEWING": 1, "CLOSED": 1}
  },
  "traceId": "demo-trace-20261027"
}
```

**业务规则**：四个状态分别对应待投递、已投递、面试中、已结束；无记录的状态返回 0。列表与统计为独立请求，修改后应刷新。
