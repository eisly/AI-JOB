# 业务后端接口（页面调用）

## 查询我的任务

**接口地址**：`/api/v1/tasks`

**请求方式**：`GET`

**请求数据类型**：`无请求体`

**响应数据类型**：`application/json`

**接口描述**：为工作台和跨页面任务抽屉提供可恢复任务列表，用户换设备或刷新后仍能找到未结束任务。

**权限**：用户。

**请求示例**：

```http
GET /api/v1/tasks HTTP/1.1

```

**请求参数**：

| 参数名称 | 参数说明 | 请求类型 | 是否必须 | 数据类型 | schema |
| --- | --- | --- | --- | --- | --- |
| Authorization | Bearer 用户accessToken | header | true | string |  |
| current | 页码≥1，默认1 | query | false | integer |  |
| size | 每页1..100，默认20 | query | false | integer |  |
| status | 可选状态，逗号分隔；不传则全部 | query | false | string |  |

**响应状态**：

| 状态码 | 说明 | schema |
| --- | --- | --- |
| 200 | 操作成功 | CommonResult&lt;Page<TaskVO>&gt; |
| 400 / 401 / 403 / 404 / 409 / 429 / 500 | 详见公共错误码 | CommonError |

**响应参数**：

| 参数名称 | 参数说明 | 类型 | schema |
| --- | --- | --- | --- |
| code | 业务码，200成功/202受理 | integer |  |
| msg | 提示信息 | string |  |
| data | 业务数据 | Page<TaskVO> | Page<TaskVO> |
| traceId | 关联排障ID | string |  |
| &emsp;total | 总数 | integer |  |
| &emsp;records | 当前页 | TaskVO[] | TaskVO |
| &emsp;current | 页码 | integer |  |
| &emsp;size | 每页大小 | integer |  |

**响应示例**：

```json
{
  "code": 200,
  "msg": "操作成功",
  "data": {
    "total": 1,
    "records": [
      {
        "id": "70000000-0000-4000-8000-000000000001",
        "type": "RESUME_PARSE",
        "status": "QUEUED",
        "stage": "等待处理",
        "progress": null,
        "resourceId": "20000000-0000-4000-8000-000000000002",
        "result": null,
        "error": null,
        "inputVersions": {
          "resumeVersionId": "20000000-0000-4000-8000-000000000002"
        },
        "lastEventId": 0,
        "createdAt": "2026-10-27T02:30:00Z",
        "finishedAt": null
      }
    ],
    "current": 1,
    "size": 20
  },
  "traceId": "demo-trace-20261027"
}
```

**业务规则**：仅本人任务；默认createdAt DESC,id DESC。任务抽屉默认筛选QUEUED,RUNNING,CANCEL_REQUESTED，历史结果可单独查询。

## 请求取消任务

**接口地址**：`/api/v1/tasks/{taskId}/cancel`

**请求方式**：`POST`

**请求数据类型**：`application/json`

**响应数据类型**：`application/json`

**接口描述**：先进入CANCEL_REQUESTED，通知Agent；完成清理后才是CANCELLED。

**权限**：用户。

**请求示例**：

```json
{}
```

| 参数名称 | 参数说明 | 请求类型 | 是否必须 | 数据类型 | schema |

**响应参数**：

| 参数名称 | 参数说明 | 类型 | schema |
| --- | --- | --- | --- |
| code | 业务码，200成功/202受理 | integer |  |
| msg | 提示信息 | string |  |

## 订阅任务事件

**接口地址**：`/api/v1/tasks/{taskId}/events`

**请求方式**：`GET`

**请求数据类型**：无请求体。

**响应数据类型**：`text/event-stream`。

**接口描述**：仅任务所有者订阅。训练评价等只发stage事件；面试生成可发delta。只有Java事务提交后才发done。所有事件的字段、重连和错误处理见[公共SSE协议](../数据模型、数据库设计与联调约定.md)。

**请求示例**：

```http
GET /api/v1/tasks/70000000-0000-4000-8000-000000000001/events HTTP/1.1
Authorization: Bearer <access-token>
Accept: text/event-stream
Last-Event-ID: 8
```

**请求参数**：

| 参数名称 | 参数说明 | 请求类型 | 是否必须 | 数据类型 | schema |
| --- | --- | --- | --- | --- | --- |
| taskId | 本人任务ID | path | true | uuid | — |
| Authorization | 用户Bearer令牌；禁止URL传token | header | true | string | — |
| Last-Event-ID | 最后已处理的任务内seq，首次缺省0 | header | false | integer | — |

**响应状态**：

| 状态码 | 说明 | schema |
| --- | --- | --- |
| 200 | 成功建立流，不等于任务成功 | TaskEvent |
| 401 / 404 / 429 | 建流前权限、资源或连接限制错误 | CommonError |
| 410 | 历史事件已过期；先查任务状态 | CommonError |

**响应参数**：

| 参数名称 | 参数说明 | 类型 | schema |
| --- | --- | --- | --- |
| id | 任务内单调seq，与data.seq一致 | integer | — |
| event | accepted / stage / delta / done / error / cancelled | string | — |
| data.taskId | 当前任务 | uuid | — |
| data.seq | 去重游标 | integer | — |
| data.payload | 按事件类型判别，见公共协议 | object | TaskEvent |

**响应示例**：

```text
id: 9
event: delta
data: {"taskId":"70000000-0000-4000-8000-000000000001","seq":9,"payload":{"text":"请介绍项目中的缓存设计"}}

id: 10
event: done
data: {"taskId":"70000000-0000-4000-8000-000000000001","seq":10,"payload":{"resourceType":"INTERVIEW","resourceId":"60000000-0000-4000-8000-000000000001","version":3}}

```

浏览器采用fetch读取流以发送Authorization和Last-Event-ID；原生EventSource不支持自定义Authorization请求头，不采用URL令牌。不要将SSE示例写成JSON数组。
