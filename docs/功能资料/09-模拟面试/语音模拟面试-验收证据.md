### 修复内容

1. InterviewResultHandler.failure 使用会话行锁，只允许当前 pending_task_id 且预期状态匹配的失败影响会话；旧失败忽略。
2. prepareRetry 检查会话锁、原任务归属和可重试状态；旧任务不能覆盖新任务。
3. report 成功回调检查当前待处理任务，防止旧报告覆盖当前报告。TaskResultService 继续负责同结果重放与不同结果冲突。
4. VoiceAnswerPanel 显式传递 TEXT/VOICE 来源，修复切换文字仍按 VOICE 提交导致缺少转写 ID 的 HTTP400；语音确认必须有转写 ID，文字无需。

## 2026-11-22 ASR 结果晚到保护矩阵

环境：MySQL 8.0.41（127.0.0.1:3307），测试库 `career_business_test`（Flyway 17）；正式库 `career_business` 未迁移。真实事务 + 受控供应商替身（可阻塞、可乱序、可注入失败），不调用付费供应商。

### 实现要点

1. 成功 / 空识别 / 失败统一条件更新：`id + attempt + status='PENDING' + consumed_at IS NULL + expires_at > UTC_TIMESTAMP(3)`，并检查受影响行数。
2. 返回后短事务二次校验：会话归属 → `WAITING_ANSWER` → 版本 → 当前题 → 记录存在 → `PENDING` → 未消费 → `attempt`；过期由 SQL 与 0 行回读裁决。
3. 0 行回读区分 EXPIRED / CONSUMED / OLD_ATTEMPT / STALE；`GONE`、旧尝试不写任何记录。
4. 已消费结果不再被同音频复用；`latest` 排除已消费；读路径按 `updated_at DESC, attempt DESC`。
5. 同题陈旧 `PENDING` 在接管前收敛为 `DISCARDED`，同一题目至多一条 PENDING。
6. 转写失效 `reason` 固定为 NOT_FOUND / CONSUMED / DISCARDED / EXPIRED，不再由状态拼接。

### 真实 MySQL 矩阵

| 场景 | 用例 | 结果 |
| --- | --- | --- |
| 正常识别返回 | `normalResultSavesExactlyOnceAndDoesNotTouchSession` | 保存一次 SUCCEEDED，题数/正式回答不变 |
| 相同音频并发上传 | `concurrentSameAudioCallsProviderOnlyOnce` | 供应商仅 1 次，第二次 TASK_IN_PROGRESS |
| 另一标签页真实提交回答 | `answerSubmittedInAnotherTabMakesLateResultStale` | 会话 GENERATING/version=2，记录 DISCARDED，USER=1、题数不增 |
| 转写期间真实结束面试 | `endingInterviewKeepsRecordDiscardedAndSessionEnding` | 会话 ENDING，记录 DISCARDED，USER=0 |
| 放弃后结果返回 | `discardedRecordCannotBeRevivedByLateResult` | 保持 DISCARDED，text 为空 |
| 过期后结果返回 | `expiredRecordStaysExpiredWhenLateResultArrives` | 保持 EXPIRED，reason=TRANSCRIPTION_EXPIRED |
| 重试后旧成功晚到 | `oldAttemptSuccessCannotOverwriteRetryAttempt` | 记录保持 attempt=2 PENDING，新尝试随后成功 |
| 旧失败晚到 | `oldAttemptFailureCannotOverwriteNewSuccess` | 新成功不被覆盖，error_key 为空 |
| 重复确认提交 | `duplicateVoiceSubmitStoresSingleAnswer` | 仅 1 条正式回答、1 个任务、1 次消费 |
| 空识别结果晚到 | `lateEmptyResultCannotReviveDiscardedRecord` | 保持 DISCARDED，不落 EMPTY |
| 放弃后同音频重试 | `retryAfterDiscardCreatesNewAttempt` | attempt=2，旧请求不影响，最终 SUCCEEDED |
| 已消费记录同音频重传 | `consumedAudioCannotBeReusedForTranscription` | 409 TRANSCRIPTION_CONSUMED，不再调用供应商 |
| 同题双 PENDING 收敛 | `stalePendingOfSameQuestionIsConvergedBeforeTakeover` | 旧记录 DISCARDED，PENDING≤1，SUCCEEDED 唯一 |
| 过期后成功/空/失败三路径 | `expiredRecordIgnoresSuccessEmptyAndFailure` | 三路径均保持 EXPIRED，text/error_key 为空 |
| V3 刷新读路径排序 | `latestTranscriptionUsesUpdatedAtThenAttempt` | 返回 updated_at/attempt 最新的新尝试 |
| 越权用户转写 | `anotherUserCannotTranscribe` | 404，不建记录、不调用供应商 |
| 不同幂等键并发提交同一转写 | `concurrentDifferentIdempotencyKeysConsumeTranscriptionOnce` | 仅 1 条 USER、1 个任务、消费指向该消息 |
