## 实测结果

**模型可用时已经复现 Web 提取从 0 到 9，但有效岗位、城市覆盖和新鲜度的整体验收尚未通过。** 同预算运行的 11 条 Agent 候选包含 8 条百度和 3 条 Web。3 条 Web 均无已确认城市及在招证据，其中一条明显偏向增长运营，随后加强了方向过滤。最终四场复跑期间 DeepSeek 返回 HTTP 402，Tavily 多轮出现超时，无法用该组结果评价模型正常供应时的最终质量。

四场平均 **86.378 秒、45.75 次 HTTP 尝试**，共 183 次 HTTP，单场最高 60 次。百度有匹配的只有基线。腾讯四场均无符合条件的岗位。Greenhouse 基线接口返回但无匹配，其余三场报告失败。企业官网搜索在基线和广州有待处理状态，未确认新官网岗位。软件测试到 API 上限后保留 41 个 Web URL。广州和软件测试合计 4 个 Web 页由确定性路径提取，城市／招聘类型和相关性过滤后各保留 1 个候选。四场 Python 岗位去重合并均为 0。

DeepSeek 四场各触发 1 次关键词调用，均收到 402，随后没有发起提取或 JD 模型调用。保留的 10 条候选均由规则完成 JD 降级，模型 JD 命中为 0。Tavily HTTP 共尝试 114 次，响应中可核对 14 credits，按公开按量价对应约 **0.112 美元**，账号实际收费以账单为准。早先模型可用的基线记录 17 Tavily credits、29,970 输入与 4,432 输出 tokens。按 DeepSeek V4-Pro 峰值及全部输入未缓存估算，已记录模型用量约 **0.057 美元**。历史基线缺 token、缓存及账单记录，无法作等口径成本对照。 [Tavily 价格](https://www.tavily.com/pricing) · [DeepSeek 价格](https://api-docs.deepseek.com/quick_start/pricing/)

### 最终版本单次基线重试

DeepSeek 仍返回 402，Tavily 部分恢复。Web 收到 **34 条命中 → 32 个唯一 URL → 20 页分析 → 1 条确定性提取**，预抓 3/9（33.3%），排除 3 个非岗位链接。达到 API 预算时保留 9 个待处理 URL，清单写入结果摘要。最终 Agent 候选为 **9 条**，包括百度 8 条与上海全栈开发实习候选 1 条。该 Web 候选在招状态未知，标题方向为全栈，无法把它计为已确认的后端在招实习。实际 59 次 HTTP 尝试，预算消耗 60，耗时 66.922 秒，Tavily 可核对 3 credits。这次单独重试没有混入四场平均值。 [最新基线原始数据](../../project/agent/data/phase3_baseline_recheck_20261112.json)

## 验证状态与未达标项

- Python 定向回归 **195 项通过**，包含模型降级、队列续跑、候选事件、结果契约、Provider、网页抓取、Chromium 动态页面和投递截止识别。
- Java 定向回归 **25 项通过**，包含 6 份真实输入的隔离回放。前端 `npm run type-check` 通过。Java 回放使用模拟持久层，未测线上数据库写入、浏览器展示或跨进程 SSE 送达。
- 有效在招岗位数量、目标城市覆盖与新鲜度尚未达到整体验收目标。模型 402、Tavily 超时和 Greenhouse 部分请求失败已实际记录。Tavily 返回恢复时，确定性路径仍可产出候选；最终重试新增候选因届次不符判为 FAIL。
- 无冻结的人工相关性标签和目标在招岗位全集，无法计算准确率、召回率或 NDCG。两个扩展场景的单条结果也不足以外推来源有效性。Brave 和 Lever 仅完成代码与模拟验证，真实数据源联调缺少配置。

## 实现范围

| 模块 | 改动与验证口径 |
| --- | --- |
| DeepSeek 与 JD | 网页岗位提取按页数与字符数分批，先从 JSON-LD、可定位的详情 HTML、页面元数据和原文引文提取，DeepSeek 补充剩余页面。岗位搜索使用非思考 JSON 请求，单次提取默认 18 秒，瞬态错误最多重试一次，401／402／403 在任务内停止后续模型调用。JD 理解仍用 DeepSeek 和原有结构，模型不可用时保留基于原文的规则降级。 |
| Planner 与数据源 | 按城市、岗位方向、求职类型轮转，按覆盖缺口补搜并把模型同义词放入后续查询。接入已有 Tavily、可选 Brave、企业招聘页、百度、腾讯与 Greenhouse／Lever 适配器。企业官网和直连来源优先启动，短暂等待后 Web 可并行。腾讯最多请求配置允许的页数，Tavily 用查询变体补搜，Brave 读取原生 offset 和下一页标志。 |
| 预算与增量 | 保留每任务 60 次检索 HTTP、150 秒总预算及最多 3 轮。官网和各直连来源有独立上限，Provider 重试、详情重定向与渲染子请求计入检索预算。待处理 URL 在轮次之间保留，预算终止后保留分来源待处理列表和结束原因。通过已有 stage SSE 携带已产出的临时候选，最终结果仍由原回调排序并保存。现有页面继续展示最终结果。 |
| 来源和质量 | 严格校验岗位标题和 JD 引文，排除薪酬汇总、站内搜索、讨论页等明显非岗位链接。保留跨来源证据、官方归属与核验四态。明确不符的城市、招聘类型、规模可淘汰。未知字段保留告警，陈旧岗位标记后在 Java 同资格组中后排。 |
| Java 和接口 | 无法识别的画像学历或无有效事实归为 UNKNOWN，只有技能要求时不认为已通过硬资格。保留现有匹配评分与分页，摘要新增资格分布、拒绝原因、截断、Agent 指标和去重数据。Agent 允许招聘类型未知，经 Java 原有未知路径处理。 |

Tavily Search 官方接口提供每次结果数和时效参数。Brave 的分页依赖 offset 和响应中的下一页标志。Greenhouse 公共 GET 返回已配置 board 的岗位。当前本机 Brave 无 Key、Lever 无 board，未报告为实测可用。百度仍使用官网公开首屏，避免依赖未经验证的翻页参数。 [Tavily Search](https://docs.tavily.com/documentation/api-reference/endpoint/search) · [Brave Web Search](https://api-dashboard.search.brave.com/app/documentation/web-search) · [Greenhouse Job Board API](https://docs.greenhouse.io/job-board.html)

## 复跑方式

在 `project/agent` 的项目 Python 环境运行。配置 Tavily 和 DeepSeek Key 可复测模型健康路径，使用现有依赖中的 Playwright 和 Chromium 可覆盖动态页面。

```powershell
python scripts/verify_job_search.py --phase-one-budget --diagnose-llm --keyword "后端开发" --cities "330100,110100,310100" --candidate-types INTERNSHIP --sources "company_official,web,baidu,tencent,greenhouse" --max-results 30 --output data/phase3_baseline_recheck.json --replay-output ../backend/target/job-search-replay/baseline.json
python -m pytest tests/test_job_search_phase2.py tests/test_search_planning.py tests/test_search_providers.py tests/test_job_search_official_priority.py tests/test_job_search_detail_fetch.py tests/test_job_search_render.py tests/test_search_metrics.py tests/test_llm.py
```

扩展场景分别替换为 `Java 后端 / 440100 / JAVA_BACKEND`、`AI Agent RAG 应用开发 / 440300 / AI_AGENT_DEVELOPER`、`软件测试 / 440100,440300,441900 / TEST`，依次对应 `--keyword`、`--cities`、`--target-role`。输出文件和回放文件按场景命名。

在 `project/backend` 回放。测试调用 Java 生产结果处理器、资格服务和匹配评分服务，写入由 Mockito 捕获。

```powershell
mvn "-Dtest=JobSearchResultHandlerTest,EligibilityServiceTest,MatchScoreServiceTest" "-DjobSearchReplayDir=target/job-search-replay" test
```

在 `project/frontend` 执行 `npm run type-check`。
