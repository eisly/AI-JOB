# 业务后端接口（页面调用）

## 查询成长摘要

**接口地址**：`/api/v1/growth`

**请求方式**：`GET`

**请求数据类型**：`无请求体`

**响应数据类型**：`application/json`

**接口描述**：展示能力估计、样本数、证据和建议，不展示录用率。

**权限**：用户。

**请求示例**：

```http
GET /api/v1/growth HTTP/1.1

```

**请求参数**：

| 参数名称 | 参数说明 | 请求类型 | 是否必须 | 数据类型 | schema |
| --- | --- | --- | --- | --- | --- |
| Authorization | Bearer 用户accessToken | header | true | string |  |

**响应状态**：

| 状态码 | 说明 | schema |
| --- | --- | --- |
| 200 | 操作成功 | CommonResult&lt;GrowthVO&gt; |
| 400 / 401 / 403 / 404 / 409 / 429 / 500 | 详见公共错误码 | CommonError |

**响应参数**：

| 参数名称 | 参数说明 | 类型 | schema |
| --- | --- | --- | --- |
| code | 业务码，200成功/202受理 | integer |  |

| &emsp;profileVersion | 当前版本 | integer |  |
| &emsp;skills | 技能与样本量 | SkillSnapshotVO[] |  |

| &emsp;suggestions | 无建议时空数组 | string[] |  |
| &emsp;suggestionTaskId | 最近建议任务 | uuid? |  |

## 生成下一步成长建议

**接口地址**：`/api/v1/growth/suggestions`

**请求方式**：`POST`

**请求数据类型**：`application/json`

**响应数据类型**：`application/json`

**接口描述**：读取当前有效证据快照，交给Learning Agent生成建议；不直接修改能力分。

**权限**：用户。

**请求示例**：

```json
{
  "expectedProfileVersion": 4
}
```

**请求参数**：

| 参数名称 | 参数说明 | 请求类型 | 是否必须 | 数据类型 | schema |
| --- | --- | --- | --- | --- | --- |
| Authorization | Bearer 用户accessToken | header | true | string |  |

| Idempotency-Key | UUID；同键同体24小时重放原结果，同键异体409 | header | true | uuid |  |

| 202 | 任务已受理；不表示结果成功 | CommonResult&lt;TaskVO&gt; |
| 400 / 401 / 403 / 404 / 409 / 429 / 500 | 详见公共错误码 | CommonError |

## 订阅任务事件

**接口地址**：`/api/v1/tasks/{taskId}/events`

**请求方式**：`GET`

**请求数据类型**：无请求体。

**响应数据类型**：`text/event-stream`。

**接口描述**：仅任务所有者订阅。训练评价等只发stage事件；面试生成可发delta。只有Java事务提交后才发done。所有事件的字段、重连和错误处理见[公共SSE协议](../数据模型、数据库设计与联调约定.md)。

**请求示例**：

```http
GET /api/v1/tasks/70000000-0000-4000-8000-000000000001/events HTTP/1.1
Authorization: Bearer <access-token>
Accept: text/event-stream
Last-Event-ID: 8
```

**请求参数**：

| 参数名称 | 参数说明 | 请求类型 | 是否必须 | 数据类型 | schema |
| --- | --- | --- | --- | --- | --- |
| taskId | 本人任务ID | path | true | uuid | — |
| Authorization | 用户Bearer令牌；禁止URL传token | header | true | string | — |
| Last-Event-ID | 最后已处理的任务内seq，首次缺省0 | header | false | integer | — |

**响应状态**：

| 状态码 | 说明 | schema |
| --- | --- | --- |
| 200 | 成功建立流，不等于任务成功 | TaskEvent |
| 401 / 404 / 429 | 建流前权限、资源或连接限制错误 | CommonError |
| 410 | 历史事件已过期；先查任务状态 | CommonError |

**响应参数**：

| 参数名称 | 参数说明 | 类型 | schema |
| --- | --- | --- | --- |
| id | 任务内单调seq，与data.seq一致 | integer | — |
| event | accepted / stage / delta / done / error / cancelled | string | — |
| data.taskId | 当前任务 | uuid | — |
| data.seq | 去重游标 | integer | — |
| data.payload | 按事件类型判别，见公共协议 | object | TaskEvent |

**响应示例**：

```text
id: 9
event: delta
data: {"taskId":"70000000-0000-4000-8000-000000000001","seq":9,"payload":{"text":"请介绍项目中的缓存设计"}}

id: 10
event: done
data: {"taskId":"70000000-0000-4000-8000-000000000001","seq":10,"payload":{"resourceType":"INTERVIEW","resourceId":"60000000-0000-4000-8000-000000000001","version":3}}

```

浏览器采用fetch读取流以发送Authorization和Last-Event-ID；原生EventSource不支持自定义Authorization请求头，不采用URL令牌。不要将SSE示例写成JSON数组。
