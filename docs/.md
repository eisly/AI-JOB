### P1 · 个人校招 JD 被标成社招

在「岗位推荐与投递 → 个人 JD」提交标题为“Java 后端开发 2027 届校园招聘”的样本。正文明确限定 2027 届应届生。解析任务成功后，列表和岗位详情均显示“社招”。个人 JD 插入语句固定写入 `EXPERIENCED`，会让后续使用招聘类型的筛选、匹配或判断基于错误分类。[浏览器证据](<C:/Users/Bread/.codex/visualizations/2026/11/10/01a1c571-9da6-7002-a9a6-6a917d712b5e/ai-job-qa/evidence/40-campus-mislabeled.txt>) · [JobMapper.java](<D:/py/AI-JOB/project/backend/src/main/java/com/aijob/backend/job/JobMapper.java:27>)

### P1 · 搜索结果丢失原始字段和来源证据

## 环境与验收边界

- 使用隔离源码副本。Java 21 与 Flyway V1–V7、MySQL 8.0、Redis 5.0、Vite、Python Agent 及本机 SMTP 收件均实际运行。Docker Desktop 启动失败后切换到本机隔离实例。认证、业务数据和回调使用真实本地服务。
- 浏览器工具的 CLI 离线缓存不可用，使用既有 Python Playwright 和 Chromium。Windows 沙箱限制了 esbuild 子进程和 Playwright 驱动管道，启动及点击使用了限于本轮 QA 的提权命令。真实调用使用已有 HTTP 代理，输入为虚构简历、画像、JD 和回答。
- 本地回放只替换岗位外部来源，并对失败和延迟进行可控注入。浏览器请求、Java 调度、Agent 执行与回调、持久化都使用正常项目路径。最初回放用了不合法的枚举，修正测试样本后的结果用于最终判定。
- 本轮覆盖 Chromium 桌面 1440×950 和三个关键页面的 390×844 检查。跨浏览器、压力、共享部署环境和招聘站点账号提交列为未执行。浏览器测试存在少量组件弃用警告，原始自动化输出保留了调试时的定位失败；最终结论采用复测及独立证据。
