## 二、执行约定

### 2.1 环境与数据

1. 记录代码版本、未提交变更、部署方式、浏览器及屏幕尺寸、数据库迁移版本、Agent 和模型配置状态；密钥、密码、Cookie、验证码及简历隐私不得写入证据。
2. 使用独立合成账号 A、B 和虚构简历、JD、投递数据；保留必要的旧画像、旧计划、历史模拟题和重复回调用例。涉及删除仅删除本次明确创建的测试数据，记录清理结果。
3. 真实模型、搜索来源、邮件和 PDF 依赖分别记录实际状态。故障注入或模拟服务用于验证边界，不代替真实模型、真实来源和真实导出的验收。外部依赖不可用时，对应真实链路标记**阻塞**并记录原因。
4. 桌面至少覆盖当前主要浏览器；移动端至少覆盖 390×844。账号、城市、时间等与平台相关的问题需在实际目标环境复测。对真实搜索样本标注时间和原始链接，人工核对在招状态。

### 2.2 结果和证据

每条用例记录：编号、版本与环境、前置条件、操作与测试数据、预期结果、实际结果、通过/失败/阻塞/未执行、截图或脱敏日志/接口证据、执行时间和问题链接。测试结果不能仅凭代码阅读或页面截图推断落库成功；涉及数据持久化的用例需刷新并结合接口或数据库核对。

**单项通过**：该项必测场景全部符合标准，且无未解决的同项高严重度问题。**整体验收通过**：约定范围内 P0、P1 全部通过，P2 通过或经项目负责人书面接受延期；无阻塞项被计为通过。模型内容质量按样本、来源和人工判断记录，不把少量样本当成总体准确率。

## 三、功能验收清单

以下编号与 [问题汇总](项目未解决问题汇总_2026-11-14.md) 的 1–16 项对应。每条以复选框记录，勾选前必须保留实际证据。

### 1. 岗位搜索、来源状态与账号隔离（P0）

- [x] **S01 搜索前状态**：分别在来源已配置、未配置和检测服务不可用的条件下打开搜索页。页面展示各来源当前检测结论、最近检测时间和可操作提示；未实际联网探测的配置检查明确标为“配置检查”，不得显示为来源连接成功；不暴露密钥。
- [ ] **S02 故障与空结果**：分别制造全部来源失败、部分失败、来源正常但无匹配、结果被筛选条件排空四种情况。提示准确区分，部分成功结果继续展示；提供重试、调整/清除筛选或导入 JD 等相应入口。匹配空态不得把无数据说成已完成有效匹配。 **本轮未通过（未完成）** 部分来源失败时仍显示有用岗位，筛选排空后正确显示筛选无结果。已复验搜索页的来源故障及正常空态，匹配页空态尚未验证。
- [ ] **S03 来源诊断**：结果显示各来源状态、返回数量和失败原因；能区分抓取、去重、过滤及匹配数量，统计与结果一致；任务中心可区分执行完成和业务结果不可用或部分失败。 **本轮未通过（失败）** 唯一来源失败和正常空结果已有不同摘要。有 1 条结果且来源部分失败时，任务摘要仍为 `OK`。
- [ ] **S04 故障恢复**：模拟超时、暂时性失败、来源恢复。重试次数及等待有界；失败源不无限阻塞其余来源；重试或稍后搜索能获得恢复后的状态。若实现熔断或缓存，验证生效条件、过期/恢复和数据时间提示，不将缓存结果冒充实时结果。 **本轮未通过（未完成）** 尚未验证同一故障来源恢复后的重试，以及缓存过期与数据时间提示。
- [ ] **S05 真实搜索**：以预先记录的多个岗位方向、城市和求职类型执行真实检索；逐条记录来源、抓取量、去重量、过滤量、有效相关量及人工核验结果。以相同条件独立进行公开网页搜索，按同一公司、同一职位去重，将人工核验有效的对照岗位作为分母；Agent 返回中可确认属于同一职位的岗位数作为分子，覆盖率须达到 **80%**。记录检索时间、原始链接、核验依据和逐项匹配情况，未能确认招聘状态的岗位单独列出；未配置来源或未达到目标应如实标记阻塞或失败，不以模拟结果替代。**历史验收未通过（阻塞）**：两组真实抽样返回 0 条和 1 条，Tavily 返回 432，DeepSeek 返回 402。**后续小样本复测未通过**：三组搜索均完成，6 个独立对照岗位中 1 条确认可用命中、1 条待核、4 条未有效命中；确认覆盖率 1/6，即使待核算作命中也仅 2/6，低于 80%。样本较小且存在选择偏差，全部 Agent 结果尚未逐条完成在招核验。[逐项证据和统计](S05真实搜索覆盖率抽样_2026-11-14.md)。
- [x] **S06 账号切换**：A 搜索后退出，B 登录访问搜索页；不恢复 A 的搜索或任务 ID，不出现因旧 ID 导致的误导性错误。失效引用可清理；直接访问无权资源被拒绝，A、B 数据不互相显示。

### 2. 训练题来源、质量与待复习（P0）

- [ ] **T01 模拟题隔离**：同库预置 fake 题，切换真实模式并创建新账号；准备多次训练，不向真实用户返回未批准的 fake 题。模拟模式仍可使用明确标识的模拟题；记录题目来源、环境及可追溯标识。 **本轮未通过（失败）** V13 引用的 `installed_at` 在 Flyway 表中不存在，实际字段为 `installed_on`。独立库执行报 MySQL 1054，启动失败。
- [ ] **T02 去重与关联**：连续练习同一技能并检查题干及 ID；同一次候选和连续练习不得无提示重复等价题干；题库不足时说明或提供有意识的复习入口。检查训练目标、岗位差距和技能是否参与选题，并人工核对题目相关性。 **本轮未通过（失败）** 无可复用的 FastAPI 题时，连续四次出题成功且题干不同，第五次仍因题干重复失败。
- [ ] **T03 回答分类**：分别提交“不会”、事实错误、正确但不完整、无关和较完整回答；区分未掌握、有效低分和无效回答。“不会”进入可识别的待复习路径，不伪造分数；错误答案按规则进入错题本，刷新后可查。 **本轮未通过（未完成）** 模拟模式五类回答已复跑，无关回答为 `INVALID`、无分且未记错题；“不会”和错误分别进入待复习及错题。真实模型评分仍受 402 限制。
- [ ] **T04 实践题**：针对要求代码、接口或测试的任务，提供与验收要求匹配的代码、附件或仓库等交付方式，或明确该题只评估文字方案；提供具体参考解析及验证清单，不把文字评分当作代码实际运行通过。 **本轮未通过（未完成）** 实践题现明确只评文字方案，并说明不运行代码。题目对应的参考解析及验证清单仍待单独验收。
- [ ] **T05 回归**：检查训练计划预算、答题、评分、错题记录和刷新恢复；真实模型与题库复用分别标明来源，测试覆盖不会、错误和完整回答。 **本轮未通过（未完成）** 模拟计划、答题、评分和错题读回通过，连续同技能出题仍可失败。真实题与错题页面的完整刷新回归尚缺。

### 3. 异步回调与任务中心（P0）

- [ ] **A01 事件顺序**：自动化集成测试覆盖同步多个 Agent 事件后写终态、并发事件及终态、重复/乱序回调；同一任务序号唯一且有序，业务结果与终态一致，重复回调幂等，不因序号冲突产生 HTTP 500 或重复业务数据。 **本轮未通过（未完成）** 并发重放和迟到回调已测，尚未验证终态落库前，不同事件与终态的并发写入。
- [ ] **A02 真实链路**：至少覆盖简历、JD、搜索、训练、项目、面试及成长建议中约定的异步操作；记录每次回调和重试。验证终态与落库结果一致，并统计错误；不得只根据最终成功认定中间过程稳定。 **本轮未通过（阻塞）** 模拟主链路再次跑通。真实简历及 JD 实测仍返回 402，缺少真实模型成功回调证据。
- [ ] **A03 状态恢复**：任务完成、失败、取消后，页面不持续显示“轮询恢复中”；网络断开再恢复时状态最终一致，刷新和查看结果可回到正确资源。 **本轮未通过（未完成）** 三类终态详情均无持续轮询，已完成搜索断网恢复后可返回正确结果。任务运行中断网到恢复的完整事件序列尚未验证。
- [ ] **A04 重试与取消**：分别模拟旧输入失效、上游超时、服务不可用和业务冲突，展示准确原因、原任务关联及可执行操作；旧版本重试说明其输入版本。对实际运行中的任务执行取消并确认终态；已终态任务不可误取消。 **本轮未通过（未完成）** 运行中取消成功，终态任务未被误取消。无可用岗位的来源失败现有独立摘要，旧输入、超时、业务冲突及页面重新搜索闭环仍未全验。
- [ ] **A05 结果摘要**：搜索无可用结果、部分失败与正常有结果在任务列表可区分；技术阶段可查看，但主状态使用可理解的业务文案。 **本轮未通过（失败）** 数据库分别写入 `NO_RESULTS_SOURCE_FAILED` 和 `EMPTY`，但部分来源失败且有结果时写入 `OK`，和正常结果仍无法区分。

### 4. 面试、项目与成长证据（P1）

- [ ] **G01 面试技能证据**：分别准备有效总评且有技能分、有效总评但无技能分、无有效评分三类结果。只为真实存在且有效的技能评分建立证据；无技能证据时报告解释原因，不将总分复制给各技能，不增加虚假的有效样本。 **本轮未通过（未完成）** 尚未覆盖有效总评但无技能分的完整场景，也缺真实模型的逐技能对照。
- [ ] **G02 项目口径**：先确认是否纳入项目任务和交付。如果纳入，完成项目并保存交付后可在成长中心查看、筛选对应来源，明确标为未评分，不增加有效评分数量；重复刷新和回调不重复计数。如果暂不纳入，应在产品和验收范围中明确记录，不以缺少功能计为已实现。 **本轮未通过（阻塞）** 成长页按自报进度处理项目。负责人尚未确认是否纳入未评分的项目交付证据。
- [ ] **G03 建议版本**：生成建议后改变画像，旧建议可查看，标注依据版本和过期原因；生成新建议后与当前版本对应。建议入口可定位到相关技能训练或项目，并保留返回路径。 **本轮未通过（未完成）** 建议的版本及过期状态已核对，跳转到相关训练或项目并返回的路径尚未验证。
- [ ] **G04 成长回归**：无评分显示无证据而非 0 分；筛选、时间线和摘要一致；测试面试不新增能力证据；历史数据与已有有效训练分保持不变。 **本轮未通过（未完成）** 无评分和零有效回答已核对，时间线、摘要及历史有效训练分的一致性尚未完整验证。

### 5. 投递去重和日期一致性（P1）
